# BLE Mesh 智能空调遥控系统用户使用指南

本文档根据你的 Notion 项目记录（页面 ID：`1cf4ff75-1d44-8018-bfc5-cc4e87090e9b`）以及代码仓库 `Solonix-Chu/BLE-MeshAC-MI` 的实现整理，重点说明：空调设备端状态灯含义、遥控器按键操作逻辑、以及常见注意事项。

## 1. 系统组成与角色

- **遥控器（Client / Provisioner）**：发起配网、下发控制指令、显示各空调状态；通常不使用状态灯提示，以屏幕为主。
- **空调设备（Server / Node）**：加入 BLE Mesh 网络后接受控制、上报状态；使用 **RGB/WS2812 状态灯**显示网络与通信状态。

## 2. 快速上手（最常用流程）

1. **给空调设备上电**：观察每台空调设备的状态灯进入“待配网”状态（见第 3 节）。
2. **给遥控器上电**：等待其完成扫描/配网（配网成功后空调设备状态灯会变化）。
3. **切换目标空调**：在遥控器待机界面，用方向键切换到目标空调页面。
4. **进入设置并下发控制**：中间键双击进入菜单 → 选择参数 → 调整数值 → 中间键单击确认发送。
5. **确认成功**：空调设备会有“收到指令”的灯效提示；遥控器在收到应答后才弹出 **SET OK**（以此为准）。

## 3. 空调设备状态灯说明（RGB/WS2812）

空调设备使用 RGB/WS2812 状态灯显示网络与通信状态（不同固件版本可能在闪烁节奏上略有差异，以颜色含义为准）：

| 颜色/灯效     | 含义                                      | 建议处理                                                |
| ------------- | ----------------------------------------- | ------------------------------------------------------- |
| 蓝色常亮      | 待配网 / 未加入网络                       | 让遥控器靠近并保持供电，等待完成配网                    |
| 绿色常亮      | 配网成功，已加入网络（在线）              | 可正常控制                                              |
| 黄色常亮/闪烁 | 心跳超时预警（通信质量下降/可能即将离线） | 缩短距离、减少遮挡、检查供电                            |
| 红色常亮/闪烁 | 异常/断开连接（将进入异常处理或离线流程） | 先确认是否被“断开/黑名单”，必要时重新允许重连或重启设备 |
| 紫色闪烁      | 成功接收到遥控器指令（确认/应答提示）     | 正常现象；若遥控器未显示 SET OK，请等待或重试一次       |

补充（实现侧的颜色映射常见为）：蓝=Provisioning、绿=Success、黄=Heartbeat、红=Error；部分版本会额外用紫色闪烁表示“收到控制指令”。

## 4. 遥控器按键与交互逻辑（五键：上/下/左/右/中）

### 4.1 按键定义

- **方向键：上/下/左/右**：在不同界面用于“切换设备/切换参数/调整数值”
- **中间键（OK）**：
  - **单击**：确认/进入下一层/应用设置
  - **双击**：进入设置菜单 / 返回待机
  - **长按（若启用）**：断开/连接当前设备（黑名单逻辑，见 5.4）

### 4.2 三态状态机（你最需要记住的规则）

遥控器的按键交互分为 3 个主要状态：

1. **S_IDLE（待机/主界面）**
   - 方向键：切换不同空调设备页面（或切到 `All Device` 群控页面）
   - 中间键双击：进入“菜单选择”

2. **S_MENU_NAVIGATE（菜单选择/参数选择）**
   - 方向键：在可设置项之间循环切换（例如：电源 → 温度 → 风速 → 模式 → ...），当前选中项通常会**闪烁**
   - 中间键单击：确认当前参数，进入“数值调节”
   - 中间键双击：返回待机

3. **S_VALUE_ADJUST（数值调节）**
   - 方向键：调整当前参数的值（例如温度±1、模式循环、风速档位切换）
   - 中间键单击：应用新值并发送控制指令，成功后返回待机
   - 中间键双击：取消本次修改并返回待机

## 5. 典型操作指南

### 5.1 单个设备配对与控制

1. 确保目标空调设备状态灯为蓝色（待配网）。
2. 遥控器上电后完成配网：空调设备状态灯由蓝色变为绿色。
3. 在遥控器待机界面切换到该空调设备页面。
4. 中间键双击进入设置菜单，选择要修改的参数（图标/选项闪烁）。
5. 中间键单击进入调节，方向键修改数值。
6. 中间键单击确认发送；空调设备紫色闪烁表示收到指令；遥控器收到应答后弹出 **SET OK** 并同步显示状态。

### 5.2 切换设备分别控制

在 **S_IDLE** 状态下，使用方向键切换不同空调设备页面；每个页面显示该设备名称与当前状态（开关/温度/模式/风速等），并可按 5.1 的流程单独下发控制指令。

### 5.3 组播群控（All Device）

1. 在 **S_IDLE** 状态切换到 `All Device` 页面。
2. 进入设置并发送控制指令后，网络中的多台空调设备会同时执行，并可观察到多台设备同步出现“收到指令”的灯效（常见为紫色闪烁）。

### 5.4 断开 / 重连设备（黑名单逻辑）

部分固件版本支持“长按中间键”对当前页面对应设备进行断开/重连控制：

1. **长按中间键**：断开当前空调设备连接 → 空调设备出现红灯提示并进入离线处理。
2. 断开后该设备可能被加入黑名单：重启后会一直蓝灯待配网但无法重新加入。
3. **再次长按中间键**：将设备移出黑名单并允许重连 → 设备恢复入网并亮绿灯。

若你的固件版本未启用该功能，请以实际 UI/菜单项为准（或联系开发者确认固件版本）。

## 6. 注意事项与常见问题

- **不要狂按键**：BLE Mesh 发送通常需要等待上一条消息发送完成或超时后才能发送下一条；建议每次操作以遥控器的 **SET OK**/提示为准。
- **黄色心跳预警**：多数是距离过远/遮挡/环境干扰导致，先把遥控器与空调设备靠近测试。
- **一直蓝灯**：
  - 可能确实未配网（首次上电）
  - 也可能被断开后进入黑名单（若启用断开功能），需要执行“允许重连”的操作
- **状态不同步**：按设计，遥控器在首次配网成功和每次重连后会向设备请求完整状态同步；若短时不同步，等待几秒或重新进入页面即可。
