# 设备控制器用户手册

欢迎使用设备控制器！本指南将帮助您了解如何使用按钮检查设备状态和更改设置。

**按键说明：**
*   **上/下箭头：** 用于在菜单中导航和更改数值。
*   **左/右箭头：** 通常可以与上/下箭头互换使用。
*   **中心按键 (OK)：** 用于选择选项和确认更改。此按钮支持单击和双击。

---

## 基本操作模式

控制器有三种主要模式：

1.  **主显示 (空闲模式)：**
    *   **您会看到什么：** 显示您设备的当前状态（例如，温度、是否开启、当前运行模式）。
    *   **如果您控制多个设备：** 使用 **上/下** (或 **左/右**) 箭头在设备之间切换，查看它们各自的状态。

2.  **选择设置 (菜单导航模式)：**
    *   **您会看到什么：** 您已进入设置菜单。其中一个设置项（如电源、模式、风速或温度）将会闪烁。
    *   此模式允许您选择*要更改哪个*设置项。

3.  **调整值 (参数调整模式)：**
    *   **您会看到什么：** 您现在专注于所选的设置项，并且可以更改其值。
    *   例如，如果您选择了“温度”，现在可以升高或降低温度值。

---

## 如何使用按键

**1. 查看设备状态 (主显示)**
   *   控制器通常显示主界面。
   *   如果您连接了多个设备，请按 **上** 或 **下** (或 **左** 或 **右**) 键循环浏览它们。

**2. 进入设置菜单**
   *   在主显示界面，**双击中心按键**。
   *   您现在处于"选择设置"模式。第一个设置项（通常是"电源"）将开始闪烁。

**3. 选择要更改的设置项 (选择设置模式)**
   *   进入"选择设置"模式后：
      *   按 **上/下** (或 **左/右**) 箭头将闪烁的高亮移动到您想要更改的设置项（例如，电源 -> 温度 -> 风速 -> 模式，然后回到电源）。
   *   当您想要调整的设置项闪烁时：
      *   **单击中心按键**。
   *   您现在已针对该特定设置项进入"调整值"模式。

**4. 更改设置项的值 (调整值模式)**
   *   进入"调整值"模式后：
      *   使用 **上/下** (或 **左/右**) 箭头更改值。
         *   示例：切换开/关、选择不同模式、增加/减少风速或温度。
      *   显示屏将显示您更改的新值。
   *   当您对新值满意时：
      *   **单击中心按键**。
   *   新设置现已保存并应用！屏幕可能会短暂显示"SET OK"。
   *   控制器将返回主显示界面。

**5. 退出设置/取消更改**

*   **快速退出：** 如果您处于"选择设置"模式或"调整值"模式，并且想要返回主显示界面而不保存任何更改，请 **双击中心按键**。
*   **超时：** 如果您在设置菜单中一段时间（例如30秒）未按任何按钮，控制器将自动返回主显示界面。您在"调整值"模式下正在进行的任何更改都将**不会**被保存。

---

**示例：更改温度**

1.  从主显示界面 **开始**。
2.  **双击中心按键** (进入"选择设置"模式，"电源"可能会闪烁)。
3.  按一次 **下箭头** (或右箭头)。"温度"现在应该在闪烁。
4.  **单击中心按键** (选择"温度"进行调整，进入"调整值"模式)。
5.  按 **上箭头** 升高温度或按 **下箭头** 降低温度。观察显示屏上的值变化。
6.  显示所需温度后，**单击中心按键**。
7.  屏幕可能会短暂显示"SET OK"，新温度已保存。您现在回到了主显示界面，显示更新后的状态。
