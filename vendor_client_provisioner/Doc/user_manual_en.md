# Device Controller User Manual

Welcome to the Device Controller! This guide will help you understand how to use the buttons to check device status and change settings.

**Buttons:**
*   **Up / Down Arrows:** Used for navigating menus and changing values.
*   **Left / Right Arrows:** Can often be used interchangeably with Up/Down arrows.
*   **Center Button (OK):** Used for selecting options and confirming changes. This button can be single-clicked or double-clicked.

---

## Basic Operation Modes

The controller has three main modes:

1.  **Main Display (Idle Mode):**
    *   **What you see:** Shows the current status of your device (e.g., temperature, whether it's on or off, current operating mode).
    *   **If you control multiple devices:** Use the **Up/Down** (or **Left/Right**) arrows to switch between devices and see their individual statuses.

2.  **Select Setting (Menu Navigation Mode):**
    *   **What you see:** You've entered the settings menu. One of the settings (like Power, Mode, Fan Speed, or Temperature) will be blinking.
    *   This mode allows you to choose *which* setting you want to change.

3.  **Adjust Value (Parameter Adjustment Mode):**
    *   **What you see:** You're now focused on the setting you selected, and you can change its value.
    *   For example, if you selected "Temperature," you can now increase or decrease the temperature value.

---

## How to Use the Buttons

**1. Viewing Device Status (Main Display)**
   *   The controller normally shows the main display.
   *   If you have multiple devices connected, press **Up** or **Down** (or **Left** or **Right**) to cycle through them.

**2. Entering Settings Menu**
   *   From the Main Display, **double-click the Center button**.
   *   You are now in "Select Setting" mode. The first setting (usually "Power") will start blinking.

**3. Choosing a Setting to Change (Select Setting Mode)**
   *   Once in the "Select Setting" mode:
      *   Press **Up/Down** (or **Left/Right**) arrows to move the blinking highlight to the setting you want to change (e.g., Power -> Temperature -> Fan Speed -> Mode, and then back to Power).
   *   When the setting you want to adjust is blinking:
      *   **Single-click the Center button**.
   *   You are now in "Adjust Value" mode for that specific setting.

**4. Changing a Setting's Value (Adjust Value Mode)**
   *   Once in "Adjust Value" mode:
      *   Use the **Up/Down** (or **Left/Right**) arrows to change the value.
         *   Examples: Toggle On/Off, select a different mode, increase/decrease fan speed or temperature.
      *   The display will show the new value as you change it.
   *   When you are happy with the new value:
      *   **Single-click the Center button**.
   *   The new setting is now saved and applied! The screen might briefly show "SET OK".
   *   The controller will return to the Main Display.

**5. Exiting Settings / Canceling Changes**

*   **Quick Exit:** If you are in "Select Setting" mode or "Adjust Value" mode and want to go back to the Main Display without saving any changes, **double-click the Center button**.
*   **Timeout:** If you don't press any buttons for a while (e.g., 30 seconds) when in a settings menu, the controller will automatically go back to the Main Display. Any changes you were in the middle of making (in "Adjust Value" mode) will **not** be saved.

---

**Example: Changing the Temperature**

1.  **Start** at the Main Display.
2.  **Double-click Center button** (enters "Select Setting" mode, "Power" is likely blinking).
3.  Press **Down arrow** (or Right arrow) once. "Temperature" should now be blinking.
4.  **Single-click Center button** (selects "Temperature" for adjustment, enters "Adjust Value" mode).
5.  Press **Up arrow** to increase the temperature or **Down arrow** to decrease it. Watch the value change on the display.
6.  Once the desired temperature is shown, **single-click Center button**.
7.  "SET OK" might appear briefly, and the new temperature is saved. You are now back at the Main Display showing the updated status.
