# BLE Mesh多跳转发功能改进

## 功能概述

本次更新优化了空调服务器的BLE Mesh多跳转发功能，确保指令、反馈和心跳包能够在多跳网络中可靠传输。

## 主要改进

### 1. 启用中继功能
```c
.relay = ESP_BLE_MESH_RELAY_ENABLED  // 从DISABLED改为ENABLED
```
- 允许设备转发其他节点的消息
- 支持构建多跳网络拓扑

### 2. 优化传输参数
```c
.net_transmit = ESP_BLE_MESH_TRANSMIT(3, 20)        // 网络传输: 3次重试，20ms间隔
.relay_retransmit = ESP_BLE_MESH_TRANSMIT(3, 20)    // 中继重传: 3次重试，20ms间隔  
.default_ttl = 7                                     // 默认TTL: 支持最多7跳
```

### 3. 心跳包多跳支持
- 使用配置的默认TTL值而不是固定值
- 添加了详细的路由日志信息
- 支持通过多跳网络发送心跳包

### 4. 状态消息路由优化
- 状态回复自动使用接收消息的路由上下文
- 支持通过多跳路径返回响应
- 保持与客户端的端到端连接

## 技术细节

### TTL (Time To Live) 配置
- **默认TTL**: 7跳
- **心跳包**: 使用默认TTL，支持长距离传输
- **状态消息**: 继承接收消息的TTL设置

### 重传机制
- **网络层**: 3次重传，20ms间隔
- **中继层**: 3次重传，20ms间隔
- **可靠性**: 显著提高消息传递成功率

### 路由信息日志
新增的日志信息包括：
```
Received MSG: opcode 0x..., src 0x..., dst 0x..., len X, TTL=Y
Sending Status: opcode 0x..., payload 0x..., to 0x..., TTL=Y
Heartbeat sent to client 0x... with TTL=Y
```

## 网络拓扑支持

### 星型网络
```
Provisioner
    ↕
AC Server (本设备)
```

### 链型网络
```
Provisioner ↔ Relay Node ↔ AC Server (本设备)
```

### 网状网络
```
    Provisioner
    ↙         ↘
Relay1      Relay2
    ↘         ↙
   AC Server (本设备)
```

## 配置监控

系统启动时会输出完整的BLE Mesh配置信息：
```
BLE Mesh Configuration:
  - Relay: ENABLED
  - Default TTL: 7
  - Network Transmit: Count=4, Interval=30ms
  - Relay Retransmit: Count=4, Interval=30ms
```

## 消息类型支持

### 自动多跳转发的消息
1. **控制指令**
   - 电源开关控制
   - 温度设置
   - 模式切换
   - 风速调节

2. **状态查询**
   - 获取当前状态
   - 状态确认响应

3. **心跳机制**
   - 定期心跳包
   - 心跳确认响应

4. **配置消息**
   - 网络配置更新
   - 中继参数调整

## 性能优化

### 传输可靠性
- 通过多次重传提高消息送达率
- 中继节点自动转发，扩大覆盖范围
- TTL机制防止消息无限循环

### 网络效率
- 合理的重传间隔减少网络拥塞
- 最大7跳限制控制网络延迟
- 智能路由选择最佳传输路径

## 调试功能

### 路由跟踪
- 记录每条消息的源地址、目标地址和TTL值
- 监控消息传输路径
- 诊断网络连通性问题

### 配置监控
- 实时显示网络配置变更
- 记录中继状态变化
- 跟踪传输参数调整

## 使用建议

### 网络部署
1. 确保中继节点均匀分布
2. 避免过长的链式连接
3. 定期检查网络连通性

### 故障排除
1. 检查TTL值是否足够
2. 验证中继功能是否启用
3. 监控重传次数和间隔

### 性能调优
1. 根据网络规模调整TTL值
2. 优化重传参数平衡可靠性与效率
3. 合理配置心跳间隔

## 兼容性

- 向后兼容单跳直连模式
- 支持动态网络拓扑变化
- 兼容标准BLE Mesh协议
